# Система зв'язку для укриття

## Запуск у Windows

Потрібні Python 3.9+ та сертифікат TLS `cert.pem` із відповідним приватним ключем `key.pem` у цій папці. Встановіть залежність:

```powershell
python -m pip install -r requirements.txt
```

Задайте секрети в PowerShell і запустіть сервер:

```powershell
$env:ROOM_CODE = "ваш-код-класу"
$env:TEACHER_CODE = "Teacher-2026"
python server.py
```

`ROOM_CODE` і `TEACHER_CODE` мають містити щонайменше 6 символів. Використовуйте різні коди та не додавайте ці значення або справжній приватний TLS-ключ до репозиторію. Учні вводять код класу, а вчитель — окремий код учителя. Сервер перевіряє код до прийняття ролі та команд.

Відкрийте `https://<адреса-сервера>:8000`. Щоб браузер дозволив доступ до мікрофона та демонстрацію екрана, використовуйте довірений браузером сертифікат, коректний для адреси сервера. Для локальних перевірок можна використовувати `localhost`.

На екрані входу можна позначити «Запам’ятати код на цьому пристрої», щоб браузер підставляв код учителя або класу під час наступного входу. Код зберігається локально у браузері без шифрування лише після успішного входу; не вмикайте цю опцію на спільному пристрої. Щоб видалити збережений код, зніміть галочку та увійдіть ще раз.

Сервер також надає `audio-worklet.js` за адресою `/audio-worklet.js`; запускайте застосунок через `server.py`, а не відкривайте HTML-файл безпосередньо.

## Транспорт

- Аудіо захоплюється через `AudioWorklet` блоками по 10 мс, передається як PCM mono 16-bit / 48 кГц і відтворюється з невеликим буфером для компенсації мережевого джиттера. Фактична затримка залежить від мережі, браузера та аудіопристроїв; гарантованої «нульової» затримки немає.
- Мікрофон і аудіо демонстрації екрана мають окремі ідентифікатори потоку. Сервер пересилає аудіо вчителя учням, а аудіо учнів — учителям; мут учня додатково перевіряється сервером.
- Кадри демонстрації передаються окремими бінарними JPEG-повідомленнями приблизно з частотою 6 кадрів/с. Перевантажені черги на клієнті пропускають кадри, щоб не накопичувати застаріле відео.
- Ідентифікатори учнів у панелі унікальні для з'єднання. Мут одного учня, мут усіх і розмут усіх — окремі команди.

Для невеликих груп сервер ретранслює медіадані всім відповідним підключеним клієнтам. Публічне розгортання потребує додаткового керування секретами, мережевих обмежень і навантажувального тестування.
